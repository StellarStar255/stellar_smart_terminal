本次更新调整终端历史记录与导出：默认关闭自动录制，按需记录单个终端，导出直接使用当前终端文本。旧历史记录保持可用，现有配置兼容。

This update makes terminal recording opt-in, records only the selected terminal, and exports text directly from the current terminal. Older recordings remain accessible and existing settings stay compatible.

## 📝 历史录制 / Terminal recording

- 启动终端不再自动录制或定期保存历史。需要时，从 History 或文件菜单选择“开始录制当前终端”；每次仅记录所选终端从此刻起的输入输出，不会随应用重启自动开启。
- Starting a terminal no longer starts automatic recording or periodic history saves. Choose Start Recording Current Terminal in History or File to capture that terminal from that point onward. Recording does not resume automatically after restarting the app.
- 切换标签不会更换录制目标，也不会混入其他标签或分屏的内容。停止、退出、关闭或跨窗口移动目标终端时保存录制，并保留已收到的尾部输出。
- Switching tabs does not change the recording target or mix in output from other tabs and panes. Recordings are saved when stopped or when the target exits, closes, or moves to another window, including received trailing output.
- History 继续支持查看、搜索和导出旧记录，并增加录制状态和动态终端界面的使用说明。Codex 等工具的完整对话请使用工具自身的会话历史。
- History still supports viewing, searching, and exporting older recordings, with recording status and guidance for dynamic terminal interfaces. Use the tool’s own session history for complete Codex conversations.

## 📤 导出 / Export

- Export 直接导出当前终端已保留的屏幕与回滚文本，无需开启录制；当前终端为空时不再误导出最近一条旧历史。
- Export saves the current terminal’s retained screen and scrollback text without requiring recording. An empty terminal no longer falls back to exporting an unrelated older session.
- 导出文本为终端解析后的快照，不包含已清除或丢弃的内容；原始录制动态界面时仍可能出现重复或错位。
- Exported text is a snapshot of the parsed terminal content and cannot recover cleared or discarded text. Raw recordings of dynamic interfaces may still contain repeated or misplaced text.

## 📥 下载 / Downloads

Windows：推荐 `*-windows-x64-setup.exe`；macOS（Apple Silicon）：推荐 `*-macOS-arm64.dmg`，也可通过应用内更新；Linux（Debian/Ubuntu）：使用 `*-linux-amd64.deb`。

Windows: use `*-windows-x64-setup.exe`. macOS (Apple Silicon): use `*-macOS-arm64.dmg` or update in-app. Linux (Debian/Ubuntu): use `*-linux-amd64.deb`.
