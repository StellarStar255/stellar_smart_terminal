本次更新增加 SSH 端口转发组合与拖拽排序，并修复窗口导航切换后的终端输入焦点。现有转发规则和配置保持兼容。

This update adds SSH port-forwarding groups and drag-to-reorder, and restores terminal input focus after switching windows through the navigator. Existing forwarding rules and settings remain compatible.

## 🔀 端口转发 / Port forwarding

- 可勾选多条端口规则，命名保存不同组合，按主机分别管理。选择组合后可一键启动或停止勾选端口，也可保存修改、另存或删除组合。
- Check multiple forwarding rules and save named groups for each host. Select a group to start or stop its checked ports together, save changes, save a new group, or delete a group.
- 支持拖拽调整规则顺序并保存；拖动不改变组合成员或端口运行状态。
- Drag forwarding rules to reorder them and retain the order. Reordering does not change group membership or running state.
- 批量启停跳过已处于目标状态的规则，不影响未勾选端口。失败时继续处理其他规则并汇总提示，保留准确的运行状态。切换组合本身不会启停端口。
- Batch operations skip rules already in the requested state and leave unchecked ports alone. Failures are summarized while other rules continue to be processed, preserving accurate running state. Selecting a group does not itself start or stop ports.

## ⌨️ 导航与输入 / Navigation and input

- 点击导航列表切换窗口后，键盘焦点自动进入目标窗口当前活跃的终端；多个分屏时保留活跃分屏，可直接输入。
- Clicking a window in the navigator now focuses its active terminal pane, so you can type immediately without clicking the terminal again.
- 同窗口点击、跨窗口切换、浮动导航和最小化恢复均交还终端焦点；快速连续切换时，过期回调不会抢回焦点。
- Focus handoff also covers clicking the current window, switching between windows, floating navigation, and restoring minimized windows. Outdated callbacks do not steal focus after rapid switches.
