本次更新为全局与本地快捷命令增加 JSON 复制和快速导入，方便在不同电脑之间迁移。现有配置保持兼容。

This update adds JSON copy and quick import for global and local quick commands, making it easier to transfer presets between computers. Existing settings remain compatible.

## 📋 快捷命令迁移 / Quick command transfer

- 管理窗口底部新增“复制全部为 JSON”，一键复制当前列表的全部快捷命令，保留顺序、中文和当前编辑内容。
- Use “Copy All as JSON” at the bottom of the manager to copy every preset in the current list, including its order, Unicode text, and current edits.
- 新增“从 JSON 快速导入”，自动填入剪贴板内容，也可手动粘贴；支持复制导出的 JSON、本地 quick_commands.json 格式和快捷命令数组。
- “Quick Import from JSON” opens with clipboard text prefilled and also accepts pasted text. It supports exported JSON, the local quick_commands.json format, and plain arrays of presets.
- 导入追加到现有列表，跳过完全相同的条目；同名但命令不同的条目会保留。格式错误时保留输入，不修改现有列表。导入后在管理窗口点 OK 保存。
- Import appends presets and skips exact duplicates. Entries with the same name but different commands are kept. Invalid input remains available for correction and leaves the existing list unchanged. Click OK in the manager afterward to save.

## 📥 下载 / Downloads

Windows：推荐 `*-windows-x64-setup.exe`；macOS（Apple Silicon）：推荐 `*-macOS-arm64.dmg`，也可通过应用内更新；Linux（Debian/Ubuntu）：使用 `*-linux-amd64.deb`。

Windows: use `*-windows-x64-setup.exe`. macOS (Apple Silicon): use `*-macOS-arm64.dmg` or update in-app. Linux (Debian/Ubuntu): use `*-linux-amd64.deb`.
