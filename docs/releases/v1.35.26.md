本次更新在目录输入框旁增加“在新窗口打开”按钮，输入项目路径即可打开独立窗口、自动运行当前预设，并记住路径供下次快速打开。现有配置保持兼容。

This update adds an “Open as New Window” button beside the directory field. Enter a project path to open a separate window, run your selected preset, and remember the directory for next time. Existing settings remain compatible.

## 🪟 项目窗口 / Project windows

- 在顶部目录输入框粘贴已有文件夹路径，点击“在新窗口打开”，即可打开独立项目窗口；沿用当前选中的命令预设，例如已配置的 Codex、Claude Code 启动命令。
- Paste an existing folder path into the Directory field and click “Open as New Window” to launch a separate project window with your selected command preset, such as your configured Codex or Claude Code command.
- 路径自动记入最近目录并持久保存，重启后仍可选择该路径重新打开。直接输入路径打开新窗口时，原窗口的目录和标签保留。
- Paths are saved in recent directories across restarts for quick reopening. Opening a typed path in a new window preserves the original window’s directory and tabs.
- 支持用户目录缩写和带空格的路径；不存在的文件夹会显示提示，不会创建窗口或记入历史。
- Supports home-directory shortcuts and paths containing spaces. A missing folder displays an error without opening a window or adding it to history.
