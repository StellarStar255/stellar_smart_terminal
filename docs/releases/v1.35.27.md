本次更新修复目录输入框在历史补全弹窗中按回车时无法正确切换的问题，并更新长路径打开新窗口的中英文演示。现有配置保持兼容。

This update fixes switching directories with Enter while history suggestions are visible, and improves the Chinese and English demos of opening a long project path in a new window. Existing settings remain compatible.

## 📁 目录切换 / Directory switching

- 目录输入框出现历史补全建议时，回车先确定要使用的路径，再执行切换，避免使用尚未补全的旧文本。Current 标签、文件树及当前标签的目录同步更新。
- When history suggestions are visible, Enter now resolves the intended path before switching. The Current label, file tree, and current tab’s directory update together.
- 直接输入完整路径并回车，会保留输入的路径，不会被默认的第一条历史建议替换成某个子目录；用方向键选择候选后再回车，则采用选中的候选。
- Enter on a typed full path preserves that path instead of replacing it with the first suggested subdirectory. Navigate suggestions with the arrow keys and press Enter to use the selected suggestion instead.
- 同时支持主键盘回车和数字键盘回车；无效路径只提示一次，不会切换或加入历史。
- Supports both Return and keypad Enter. An invalid path displays one error without switching or adding it to history.
