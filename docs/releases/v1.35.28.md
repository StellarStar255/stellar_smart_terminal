本次更新精简目录工具栏，移除重复的 Switch（切换）按钮。

This update simplifies the directory toolbar by removing the redundant Switch button.

## 目录切换 / Directory switching

- 手动输入目录路径后按回车即可切换，输入框新增中英文提示。
- Type a directory path and press Enter to switch. The input now includes a localized hint.
- 从历史列表选择目录、通过 Browse 浏览选择目录，仍会自动切换；补全确认和“在新窗口打开”功能保持可用。
- Selecting a directory from history or Browse still switches automatically. Completion confirmation and Open as New Window remain available.

## 下载 / Downloads

Windows：推荐 `*-windows-x64-setup.exe`；macOS（Apple Silicon）：推荐 `*-macOS-arm64.dmg`，也可通过应用内更新；Linux（Debian/Ubuntu）：使用 `*-linux-amd64.deb`。

Windows: use `*-windows-x64-setup.exe`. macOS (Apple Silicon): use `*-macOS-arm64.dmg` or update in-app. Linux (Debian/Ubuntu): use `*-linux-amd64.deb`.
