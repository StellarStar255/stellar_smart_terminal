目录栏新增“← 返回”按钮，一键返回当前标签页之前所在的目录。

The directory toolbar now includes an “← Back” button to return to the previous directory in the current tab.

## 目录返回 / Directory navigation

- “浏览”旁新增返回按钮，连续点击可按切换顺序逐步返回；没有历史时按钮置灰。
- Click Back beside Browse to step through earlier directories. The button is disabled when no history is available.
- 每个标签页独立记录本次运行中的目录切换历史，重复选择同一目录不会增加记录，已删除的目录自动跳过。
- Each tab keeps its own navigation history for the current session. Repeated selections of the same directory do not add entries, and deleted folders are skipped.
- 返回时同步更新目录栏、资源管理器、Git 面板和当前标签页终端的工作目录设置。
- Going back updates the directory field, Explorer, Git panel, and the working-directory settings of terminals in the current tab.

## 下载 / Downloads

Windows：推荐 `*-windows-x64-setup.exe`；macOS（Apple Silicon）：推荐 `*-macOS-arm64.dmg`，也可通过应用内更新；Linux（Debian/Ubuntu）：使用 `*-linux-amd64.deb`。

Windows: use `*-windows-x64-setup.exe`. macOS (Apple Silicon): use `*-macOS-arm64.dmg` or update in-app. Linux (Debian/Ubuntu): use `*-linux-amd64.deb`.
