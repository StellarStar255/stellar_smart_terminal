Opening a directory in a new window now restores the original window’s previous directory. Directory toolbar controls also use consistent sizing and styling.

## 目录与窗口 / Directories and windows

- 手动输入新路径后点击“在新窗口打开”，原窗口目录框恢复原来的工作路径。
- After typing a new path and clicking Open as New Window, the original directory field returns to its working directory.
- 通过浏览或历史列表切换到新目录后，再在新窗口打开，原窗口自动返回上一个目录，同步更新目录框、资源管理器、Git 面板和终端工作目录设置。
- After selecting a directory through Browse or history, opening it in a new window returns the original window to the previous directory and updates its directory field, Explorer, Git panel, and terminal working-directory settings.
- 统一返回、浏览和新窗口按钮的高度、字号、圆角及内边距，历史下拉按钮同步对齐，支持中英文和 GUI 字号调整。
- Back, Browse, and Open as New Window share consistent height, font size, corners, and padding. The history dropdown aligns with these controls across languages and GUI font sizes.
