修复 SSH 端口转发停止后重新启动时误报“本机端口已被占用”的问题。现有连接配置保持兼容。

Fixes false “local port already in use” errors when restarting SSH port forwarding after stopping it. Existing connection settings remain compatible.

## 端口转发 / Port forwarding

- 修复旧 TCP 连接处于 TIME_WAIT 状态时被误判为端口占用，停止转发后可立即重新启用本地转发或 SOCKS5 转发。
- Closed TCP connections in TIME_WAIT no longer cause false port-in-use errors when restarting local or SOCKS5 forwarding.
- 保留对实际监听服务的占用检测；停止监听后仍存活的旧连接不会被主动断开。
- Actual listening services are still detected as conflicts, and existing connections are preserved after the listener stops.

## 下载 / Downloads

Windows：推荐 `*-windows-x64-setup.exe`；macOS（Apple Silicon）：推荐 `*-macOS-arm64.dmg`，也可通过应用内更新；Linux（Debian/Ubuntu）：使用 `*-linux-amd64.deb`。

Windows: use `*-windows-x64-setup.exe`. macOS (Apple Silicon): use `*-macOS-arm64.dmg` or update in-app. Linux (Debian/Ubuntu): use `*-linux-amd64.deb`.
