修复启动恢复窗口后，目录栏 Back 按钮被误启用的问题。

Fixes the directory Back button becoming available immediately after restoring a window at startup.

## 修复 / Fix

- 恢复上次工作区或升级前窗口时，不再把启动时的默认目录加入返回历史。恢复完成后，尚未手动切换目录的窗口中 Back 保持禁用。
- Restoring a workspace or a window after an update no longer adds the startup default directory to Back history. Back stays disabled until you change directories.
- 手动切换目录后，仍可返回恢复的项目目录；新窗口的返回历史保持独立。
- After a manual directory change, Back returns to the restored project directory. New windows keep independent navigation history.

## 下载 / Downloads

Windows：推荐 `*-windows-x64-setup.exe`；macOS（Apple Silicon）：推荐 `*-macOS-arm64.dmg`，也可通过应用内更新；Linux（Debian/Ubuntu）：使用 `*-linux-amd64.deb`。

Windows: use `*-windows-x64-setup.exe`. macOS (Apple Silicon): use `*-macOS-arm64.dmg` or update in-app. Linux (Debian/Ubuntu): use `*-linux-amd64.deb`.
