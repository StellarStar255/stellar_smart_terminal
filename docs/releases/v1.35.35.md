右键菜单新增“新建终端”，并调整新建终端与窗口的默认快捷键。

Adds New Terminal to the context menu and updates the default terminal and window shortcuts.

## 终端 / Terminal

- 终端右键菜单顶部新增“新建终端”，在当前本地目录打开新标签页并立即启动默认 shell。菜单显示当前生效的快捷键。
- New Terminal appears at the top of the terminal context menu. It opens a new tab in the current local directory and starts the default shell. The menu shows the effective shortcut.
- macOS：⌘N 新建终端，⌘⇧N 新建窗口；Windows/Linux 对应 Ctrl+N、Ctrl+Shift+N。
- On macOS, use ⌘N for a new terminal and ⌘⇧N for a new window. On Windows/Linux, the corresponding shortcuts are Ctrl+N and Ctrl+Shift+N.
- 保留 ⌘T / Ctrl+T 原有的新建标签页功能。预设会话仍可从菜单启动，默认不再占用 ⌘⇧N / Ctrl+Shift+N；快捷键设置和速查表同步更新。
- ⌘T / Ctrl+T retains its existing New Tab behavior. Preset sessions remain available from the menu and no longer use ⌘⇧N / Ctrl+Shift+N by default. Shortcut settings and the cheat sheet reflect the new defaults.

## 下载 / Downloads

Windows：推荐 `*-windows-x64-setup.exe`；macOS（Apple Silicon）：推荐 `*-macOS-arm64.dmg`，也可通过应用内更新；Linux（Debian/Ubuntu）：使用 `*-linux-amd64.deb`。

Windows: use `*-windows-x64-setup.exe`. macOS (Apple Silicon): use `*-macOS-arm64.dmg` or update in-app. Linux (Debian/Ubuntu): use `*-linux-amd64.deb`.
