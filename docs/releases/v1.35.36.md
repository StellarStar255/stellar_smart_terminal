修复退出再打开后，各窗口的预设选择和终端窗口列表顺序丢失的问题。

Fixes lost per-window preset selections and terminal window list ordering after restarting.

## 窗口与预设 / Windows and presets

- 工作区恢复时按名称恢复每个窗口各自选择的 Preset，预设列表调整顺序后仍能找回对应选项。旧快照未记录的选择无法追溯恢复。
- Workspace restore remembers each window’s selected preset by name, including after the preset list is reordered. Selections missing from older snapshots cannot be recovered retroactively.
- 终端窗口列表记住排序模式和拖拽后的手动顺序，并在重新打开工作区后恢复；Compact、Quick Close 等现有选项继续保存。
- The terminal window list now saves its sort mode and manual drag order across workspace restarts. Existing Compact and Quick Close preferences remain persistent.
- 退出前刷新完整工作区快照，防止逐个关闭窗口时把快照覆盖成只剩部分窗口。
- Quit refreshes the complete workspace snapshot before closing windows and prevents subsequent windows from replacing it with a partial snapshot.
- 编辑预设时保留当前选择，成功保存后清除修改标记，避免旧窗口退出时重新写回旧预设。
- Preset edits preserve the current selection. Successful saves clear the modified flag so an older window cannot rewrite stale presets when closing.
- 恢复窗口仍不自动启动终端会话。
- Restored windows continue to leave terminal sessions stopped.

## 下载 / Downloads

Windows：推荐 `*-windows-x64-setup.exe`；macOS（Apple Silicon）：推荐 `*-macOS-arm64.dmg`，也可通过应用内更新；Linux（Debian/Ubuntu）：使用 `*-linux-amd64.deb`。

Windows: use `*-windows-x64-setup.exe`. macOS (Apple Silicon): use `*-macOS-arm64.dmg` or update in-app. Linux (Debian/Ubuntu): use `*-linux-amd64.deb`.
