切换默认 Preset 时，所有终端窗口同步使用同一选项。

Synchronizes the default Preset selection across all terminal windows.

## 预设 / Presets

- 任一窗口切换 Preset，其余窗口立即同步，之后点击 Start 使用新选项。
- Selecting a Preset in any window updates every window. Subsequent Start actions use the selected preset.
- 保存全局默认选择，新开窗口和重启后继续沿用；旧工作区快照中的单独选择不再覆盖全局默认值。
- Saves the global default for new windows and restarts. Older per-window workspace selections no longer override it.
- 已运行的 Codex、Shell 等会话继续保留，不自动停止或重启。
- Running Codex, shell, and other terminal sessions remain active without being stopped or restarted.

## 下载 / Downloads

Windows：推荐 `*-windows-x64-setup.exe`；macOS（Apple Silicon）：推荐 `*-macOS-arm64.dmg`，也可通过应用内更新；Linux（Debian/Ubuntu）：使用 `*-linux-amd64.deb`。
