优化 Codex 等全屏终端应用中的跨页文本框选与复制。

Improves text selection across scrolling pages in full-screen terminal applications such as Codex.

## 终端选择 / Terminal selection

- 按住鼠标拖到终端上下边缘时，向全屏应用转发滚动，让选区继续扩展；按住鼠标使用滚轮也支持跨页选择。
- Dragging to the top or bottom edge scrolls the full-screen application and extends the selection. Scrolling the wheel while selecting also extends it across pages.
- 保存离屏选中文本，通过相邻页面的重叠行对齐，支持连续翻页与反向拖回，减少重绘造成的内容丢失或重复。
- Retains selected text that leaves the screen and aligns overlapping rows across pages, including when reversing direction.
- 跨页复制排除固定标题、输入栏和 “Back to bottom” 提示；中文与软换行沿用现有复制规则。
- Excludes fixed headers, input areas, and the “Back to bottom” indicator from cross-page copies, preserving existing Chinese text and soft-wrap handling.
- 等待应用重绘并限制滚动步长，避免快速滚动跳过页面；窗口尺寸或屏幕模式变化时中止进行中的选区，避免坐标错位。
- Waits for application redraws and limits scroll steps to retain overlap. Cancels active selection when the terminal dimensions or screen mode change.

## 下载 / Downloads

Windows：推荐 `*-windows-x64-setup.exe`；macOS（Apple Silicon）：推荐 `*-macOS-arm64.dmg`，也可通过应用内更新；Linux（Debian/Ubuntu）：使用 `*-linux-amd64.deb`。

Windows: use `*-windows-x64-setup.exe`. macOS (Apple Silicon): use `*-macOS-arm64.dmg` or update in-app. Linux (Debian/Ubuntu): use `*-linux-amd64.deb`.
