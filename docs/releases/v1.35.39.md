本地快速命令内置默认 Shell，无需逐项目配置即可使用。

Local Quick Commands now includes a built-in shell action, available without per-project configuration.

## 本地快速命令 / Local Quick Commands

- 菜单顶部始终显示默认 Shell，没有自定义命令的项目也能直接使用。
- A built-in shell action always appears at the top of the menu, including projects with no custom commands.
- macOS/Linux 优先使用系统默认 Shell，如 zsh 或 bash；Windows 优先使用 PowerShell 7（pwsh），其次 Windows PowerShell，不可用时回退到 cmd。
- macOS/Linux use the system's default shell, such as zsh or bash. Windows prefers PowerShell 7 (pwsh), then Windows PowerShell, with cmd as a fallback.
- 保留自定义项目命令及其顺序，不向项目配置中写入内置项；命令沿用原有的当前终端执行方式。
- Custom project commands and their order are preserved. The built-in action is not written to project configuration and uses the existing command execution path in the current terminal.

## 发布流程 / Release workflow

- 延长 Mac 构建、公证和测试作业的超时上限，减少 Apple 公证排队造成的重复构建；保留三平台测试及完整附件发布检查。
- Extends the macOS job timeout to accommodate Apple notarization queues, retaining tests on all three platforms and the complete-installer publication check.

## 下载 / Downloads

Windows：推荐 `*-windows-x64-setup.exe`；macOS（Apple Silicon）：推荐 `*-macOS-arm64.dmg`，也可通过应用内更新；Linux（Debian/Ubuntu）：使用 `*-linux-amd64.deb`。

Windows: use `*-windows-x64-setup.exe`. macOS (Apple Silicon): use `*-macOS-arm64.dmg` or update in-app. Linux (Debian/Ubuntu): use `*-linux-amd64.deb`.
