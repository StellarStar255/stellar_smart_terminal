文件浏览器支持快捷键返回上级目录。

Explorer now supports a keyboard shortcut to navigate to the parent folder.

## 文件浏览器 / Explorer

- macOS：在文件浏览器内按 **⌘↑**，返回上级目录。
- On macOS, press **⌘↑** while focused in Explorer to navigate to the parent folder.
- Windows/Linux：使用 **Alt+↑**。
- On Windows/Linux, use **Alt+↑**.
- 快捷键仅在文件浏览器及其子控件（如搜索框）获得焦点时生效，不占用终端或其它面板的按键。
- The shortcut applies only while Explorer or one of its child controls, such as the search field, has focus. Terminal and other panel shortcuts remain available.
- 普通上下键继续用于文件列表导航；位于文件系统根目录时，返回上级操作保持不动。
- Plain arrow keys still navigate the file list. At the filesystem root, parent navigation leaves the current folder unchanged.
- “上一级”按钮的提示中显示当前平台的快捷键。
- The parent-folder button tooltip shows the platform's shortcut.

## 下载 / Downloads

Windows：推荐 `*-windows-x64-setup.exe`；macOS（Apple Silicon）：推荐 `*-macOS-arm64.dmg`，也可通过应用内更新；Linux（Debian/Ubuntu）：使用 `*-linux-amd64.deb`。

Windows: use `*-windows-x64-setup.exe`. macOS (Apple Silicon): use `*-macOS-arm64.dmg` or update in-app. Linux (Debian/Ubuntu): use `*-linux-amd64.deb`.
