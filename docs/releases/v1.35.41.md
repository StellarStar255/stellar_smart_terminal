修复 Codex 中拖到终端边缘后，页面不继续滚动、无法跨页框选的问题。

Fixes edge scrolling and cross-page text selection in Codex.

## 终端选择 / Terminal selection

- 拖到输入栏、状态栏或窗口边缘时，仍向正文内的坐标发送滚轮，避免 Codex 忽略正文外的滚轮事件。
- When dragging over the input area, status bar, or window edge, wheel reports use an interior transcript position so Codex can continue scrolling.
- 支持从置顶用户消息开始选择；页面未移动时会尝试内部坐标，少量状态文字刷新不会阻断重试。
- Supports selections starting on pinned user messages. Retries an interior position when the page has not moved, without being blocked by minor status updates.
- 每次只发送一格滚轮，减少应用滚速叠加导致的整页跳跃；页面尚未对齐时等待重绘，保留跨页文本。
- Sends one wheel notch at a time to avoid multiplying application scroll speed into full-page jumps, and waits for alignment during substantial redraws.
- 修复单独关闭一种鼠标模式时，误把其它已启用模式一起视为关闭的问题。
- Keeps mouse reporting active when one mode is disabled but other mouse modes remain enabled.
- 增加按 Codex 正文区域规则工作的真实 PTY 回归，覆盖 Qt 定时滚动、多页连续复制、置顶起点与固定底栏排除。旧滚轮逻辑可在这些用例中复现失败。
- Adds a real PTY fixture following Codex's transcript hit-testing rules, covering Qt timer scrolling, multi-page copying, pinned-message starts, and fixed-footer exclusion. The released wheel logic reproduces failures in these tests.

## 发布流程 / Release workflow

- 更新云端公证凭据并增加构建前预检，防止凭据失效后继续打包；重跑流程不会覆盖已公开版本的安装包。
- Refreshes cloud notarization credentials and adds a preflight check. Reruns leave published installers unchanged.
