修复终端在持续输出、搜索、调整尺寸、粘贴和关闭时的多处卡顿与假死问题。

Fixes terminal stalls during sustained output, searching, resizing, pasting, and closing.

## 终端响应 / Terminal responsiveness

- 屏幕解析或重排繁忙时，界面沿用上一帧；全屏程序的选区重绘也不会等待屏幕锁。
- Reuses the previous frame while parsing or reflow is busy, including selections in full-screen applications, instead of blocking the interface on the screen lock.
- 搜索、尺寸调整及重排收尾、命令完成检测在屏幕繁忙时稍后重试，保留最新查询、目标尺寸及待发送的提醒。
- Defers searches, resizing and reflow completion, and command-completion detection while the screen is busy, preserving the latest query, target dimensions, and pending notifications.
- 原生工作目录查询失败时，在后台运行备用查询并合并重复请求，避免切换标签或分屏时等待外部命令。
- Runs fallback working-directory lookups in the background and coalesces repeated requests, avoiding external-command waits when switching tabs or splitting terminals.
- 调整应用启动时的 Python 线程调度，改善多个终端同时大量输出时的界面响应。
- Adjusts Python thread scheduling at application startup to improve responsiveness when several terminals produce heavy output simultaneously.

## 粘贴与关闭 / Pasting and shutdown

- macOS 原生剪贴板脚本改为异步执行，保留连续粘贴顺序、完整文件路径、截图及括号粘贴协议，并处理超时、启动失败和临时文件清理。
- Runs native macOS clipboard scripts asynchronously, preserving paste order, complete file paths, raster-image paste, and bracketed paste, with timeout, startup-failure, and temporary-file handling.
- 剪贴板、终端会话已变化或终端已关闭时，不再投递过期的粘贴结果。
- Discards pending paste results when the clipboard or terminal session changes, or the terminal closes.
- 关闭终端时可以取消读取线程对屏幕锁的等待，避免在界面线程中等待后台重排；关闭后的输出、定时器和重排回调不再重启工作。
- Cancels reader waits on the screen lock during shutdown, avoiding waits for background reflow on the GUI thread. Late output, timer, and reflow callbacks no longer restart work after cleanup.
- Unix 读取遇到暂时无数据或系统调用中断时继续处理，并保留已读取的输出，避免误判为终端关闭。
- Continues Unix reads after temporary unavailability or interrupted system calls, retaining already-read output instead of treating these conditions as terminal closure.

## 验证 / Validation

- 增加屏幕锁竞争、关闭取消、异步粘贴顺序与超时、工作目录后台查询和线程调度回归测试；真实 macOS 文件和图片粘贴使用独立命名剪贴板验证。
- Adds regressions for screen-lock contention, shutdown cancellation, asynchronous paste ordering and timeouts, background working-directory lookups, and thread scheduling. Real macOS file and image paste is verified with isolated named pasteboards.
- 本机四终端持续输出约 6.5 万行的对比测试中，界面事件间隔的第 95 百分位从约 146 毫秒降至 34 毫秒，输出总耗时基本不变；结果随机器与负载变化。
- In a local comparison with four terminals producing roughly 65,000 lines, the 95th-percentile GUI event gap fell from approximately 146 ms to 34 ms with essentially unchanged output time. Results vary by hardware and workload.
