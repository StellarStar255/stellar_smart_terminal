改善终端粘贴、中断与会话重启的可靠性，修复退出后资源残留及延迟命令发送到错误会话的问题。

Improves terminal paste, interrupt, and restart reliability, fixing retained resources after exit and delayed commands reaching the wrong session.

## 粘贴与中断 / Pasting and interrupts

- 文件、图片上传与后续键入、回车、鼠标上报按操作顺序发送；图片编码和文件保存转到后台，积压输入分批回放，保持界面响应。
- Preserves ordering between file and image uploads, typing, Enter, and mouse reports. Image encoding and file saving run in the background, with queued input replayed in batches to keep the interface responsive.
- Ctrl+C 取消未发送的粘贴和上传任务，大块输入或写入队列已满时优先处理中断；中断括号粘贴时补上结束标记。
- Ctrl+C cancels unsent paste and upload tasks and takes priority during bulk input or a full input queue, closing bracketed paste before sending the interrupt.
- 处理连续粘贴、剪贴板变化、上传取消与失败，并使用独立远端文件名避免同名文件相互覆盖。
- Handles repeated pastes, clipboard changes, and upload cancellation and failures, using distinct remote filenames to avoid overwriting files with the same name.

## 会话生命周期 / Session lifecycle

- shell 退出后释放输入线程和 PTY 等资源，取消待处理的粘贴任务，同时保留终端输出供查看。
- Releases input threads and terminal I/O resources and cancels pending paste tasks when the shell exits, while retaining output for review.
- 终端重置后恢复粘贴和方向键模式；重启会话时恢复默认终端协议状态，退出遗留的备用屏幕，保留主屏内容及历史。
- Restores paste and cursor-key modes after a terminal reset. Restarted sessions use default protocol state and leave any inherited alternate screen while retaining main-screen content and history.
- 屏幕正在后台重排时延后启动，不阻塞界面；停止或替换会话会取消旧启动请求和延迟命令。
- Defers startup during background screen reflow without blocking the interface. Stopping or replacing a session invalidates old startup requests and delayed commands.
- 快捷命令和 SSH 启动命令等待本次 shell 启动完成；堡垒机初始化不再依赖 API 服务的输出监听，且不会把旧初始化命令发送到新会话。
- Quick commands and SSH startup commands wait for their shell to start. Bastion initialization no longer depends on API-server output monitoring and cannot send old initialization commands into replacement sessions.

## 验证 / Validation

- 本机完整测试：1950 项通过、16 项跳过，另有 118 项子测试通过；静态检查通过。
- Local full suite: 1,950 tests passed, 16 skipped, plus 118 passing subtests; static checks passed.
- 增加真实 PTY 中断、会话退出释放资源、重启后的粘贴、后台重排期间启动，以及延迟命令会话隔离回归测试。
- Adds regressions for interrupts in a real PTY, resource release after exit, pasting after restart, startup during background reflow, and session isolation for delayed commands.
- 三个平台的打包与测试由发布流水线执行；本机验证结果不替代跨平台验收。
- The release workflow builds and tests all three platforms; local results do not replace cross-platform validation.
