新建终端即可直接输入命令，本地快速命令菜单只保留用户配置的命令。

New terminals open an interactive shell immediately, while Local Quick Commands contains only user-configured commands.

## 终端启动 / Terminal startup

- 新建标签页（包括“＋”、快捷键和终端菜单）、分屏、新窗口以及首次打开应用时，自动启动交互 shell。
- Automatically starts an interactive shell for new tabs, including the + button, shortcuts, and terminal menus, as well as splits, new windows, and initial application startup.
- macOS/Linux 使用系统默认 shell；Windows 优先 PowerShell 7，其次 Windows PowerShell，均未安装时回退到 cmd。
- Uses the system default shell on macOS/Linux. Windows prefers PowerShell 7, then Windows PowerShell, falling back to cmd if neither is available.
- 新终端继承对应工作目录，重复初始化不会再嵌套启动一层 shell。自定义预设与 SSH 保留各自的启动流程。
- New terminals use their corresponding working directory, and repeated initialization does not nest another shell. Custom presets and SSH retain their own startup flows.

## 本地快速命令 / Local Quick Commands

- 移除程序固定插入的 zsh、bash、PowerShell 等 shell 项，只显示用户配置的本地命令。
- Removes the built-in zsh, bash, or PowerShell menu entry, showing only user-configured local commands.
- 保留已有命令的名称、顺序及内容；用户自行配置的 shell 命令仍然保留。“添加命令”和“管理本地预设”入口继续可用。
- Preserves existing command names, ordering, and contents, including explicitly configured shell commands. Add Command and Manage Local Presets remain available.

## 验证 / Validation

- 本机全量测试：1953 项通过、16 项跳过，另有 120 项子测试通过；静态检查通过。
- Local full suite: 1,953 tests passed, 16 skipped, plus 120 passing subtests; static checks passed.
- 真实 shell 验证新终端可直接执行输入、重复初始化保留同一后端，以及本地命令菜单不再插入默认 shell。
- Verifies with a real shell that new terminals accept commands immediately, repeated initialization keeps the same backend, and the local command menu no longer inserts a default shell.

Windows: use `*-windows-x64-setup.exe`. macOS (Apple Silicon): use `*-macOS-arm64.dmg` or update in-app. Linux (Debian/Ubuntu): use `*-linux-amd64.deb`.
