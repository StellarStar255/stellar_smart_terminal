Remote Explorer 搜索更快，结果边搜边显示，并可直接右键操作、批量复制和粘贴文件。

Remote Explorer searches now stream results as they arrive, with context menus, multiple selection, and file copy/paste directly in search results.

## 搜索性能 / Search performance

- 优先通过独立 SSH 通道在服务器端扫描文件名，减少逐目录 SFTP 网络往返，避免搜索排在文件传输任务后面。
- Scans filenames on the server over a separate SSH channel, reducing per-directory SFTP round trips and avoiding the file transfer queue.
- 搜索结果即时分批显示；更换关键词、导航或关闭窗口时取消旧搜索，并加入超时保护。
- Displays matches incrementally, cancels stale searches when changing the query, navigating, or closing the panel, and bounds remote search time.
- 远端缺少 Python 3 或不支持执行命令时自动回退到 SFTP；达到扫描范围、数量或时间限制时明确提示搜索未完成。
- Falls back to SFTP when remote Python 3 or command execution is unavailable, and reports incomplete scans when scope, result, or time limits are reached.

## 搜索结果操作 / Search result actions

- 补齐右键菜单：打开文件、打开目录或所在目录、终端、复制、粘贴、重命名、删除、下载和复制路径。
- Adds context menu actions for opening files, directories and containing folders, terminals, copy/paste, rename, delete, download, and copying paths.
- 支持多选与 Cmd/Ctrl+C、Cmd/Ctrl+V；操作只读取当前可见列表的选中项，不再误用隐藏文件树的旧选择。
- Supports multiple selection and Cmd/Ctrl+C and Cmd/Ctrl+V, using the visible file selection rather than stale selections in the hidden tree.
- 选中文件时粘贴到其父目录，选中文件夹时粘贴到目录内；无选中项时粘贴到搜索根目录，同目录复制保留自动重命名规则。
- Pastes beside a selected file, inside a selected directory, or into the search root when nothing is selected. Same-folder copies retain automatic duplicate naming.
- 重命名、删除、粘贴、上传和刷新后保留搜索条件；流式结果更新时保留多选和滚动位置，搜索输入框保留原有文本复制快捷键。
- Retains the search query after rename, delete, paste, upload, and refresh. Streaming updates preserve multiple selection and scroll position, while the search input keeps native text clipboard shortcuts.
- 修复批量下载回调参数错误，并支持从右键菜单下载单个目录。
- Fixes the batch download action callback and supports downloading a single directory from its context menu.

## 验证 / Validation

- 本机全量测试：1977 项通过、16 项跳过，另有 120 项子测试通过；静态检查通过。
- Local full suite: 1,977 tests passed, 16 skipped, plus 120 passing subtests; static checks passed.
- 覆盖服务器扫描、取消与超时、SFTP 回退、真实 Qt 快捷键事件、多选右键操作和嵌套目录粘贴的回归测试。
- Regression coverage includes server scanning, cancellation and timeouts, SFTP fallback, real Qt shortcut events, multiple-selection context actions, and nested-directory paste destinations.

## 下载 / Downloads

Windows：推荐 `*-windows-x64-setup.exe`；macOS（Apple Silicon）：推荐 `*-macOS-arm64.dmg`，也可通过应用内更新；Linux（Debian/Ubuntu）：使用 `*-linux-amd64.deb`。

Windows: use `*-windows-x64-setup.exe`. macOS (Apple Silicon): use `*-macOS-arm64.dmg` or update in-app. Linux (Debian/Ubuntu): use `*-linux-amd64.deb`.
