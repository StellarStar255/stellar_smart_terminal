Markdown 源码编辑区支持直接粘贴截图和复制的本地图片文件，自动保存图片并插入相对路径引用。

Paste screenshots and copied local image files directly into the Markdown source editor, with automatic asset saving and relative image references.

## Markdown 图片粘贴 / Markdown image paste

- 在 `.md` 和 `.markdown` 源码编辑区使用 Cmd/Ctrl+V 或右键“粘贴”，可直接插入剪贴板图片；纯图片剪贴板也会启用粘贴操作。
- Use Cmd/Ctrl+V or the Paste context menu action in `.md` and `.markdown` source editors to insert clipboard images. Image-only clipboards now enable Paste.
- 图片默认保存到当前 Markdown 文件所在目录的 `assets/`，并在光标处插入 `![image](assets/image_….png)` 等相对路径引用，不依赖应用启动目录。
- Saves images in `assets/` beside the current Markdown file and inserts relative references such as `![image](assets/image_….png)` at the cursor, independently of the application's working directory.
- 截图保存为 PNG；复制的本地图片文件保留原始文件内容，支持一次粘贴多张图片。每次粘贴生成独立文件名，避免覆盖已有图片。
- Saves screenshots as PNG and preserves original bytes for copied image files, including multiple images in one paste. Each paste uses distinct filenames to avoid overwriting existing assets.
- 图片引用支持一次撤销、重做；保存后重新打开及 Markdown 预览均能加载相对路径图片。
- Image reference insertion supports single-step undo and redo. Relative images remain available after saving and reopening, and in Markdown preview.
- 图片写入失败时明确提示并保留原文；多张图片中途失败会清理本次已保存的图片。普通文本粘贴和只读编辑器行为保持正常。
- Reports image write failures while preserving the original text, and cleans up newly saved assets if a multi-image paste fails. Plain text paste and read-only editor behavior remain intact.

- Local full suite: 1,986 tests passed, 16 skipped, plus 120 passing subtests; static checks passed.
- 回归测试覆盖真实 Qt 粘贴快捷键、图片像素与透明度、相对路径预览、多图粘贴、撤销重做、保存重开及写入失败回滚。
- Regression tests cover actual Qt paste shortcuts, image pixels and transparency, relative-path preview, multiple images, undo and redo, save and reopen, and rollback on write failure.

## 下载 / Downloads

Windows：推荐 `*-windows-x64-setup.exe`；macOS（Apple Silicon）：推荐 `*-macOS-arm64.dmg`，也可通过应用内更新；Linux（Debian/Ubuntu）：使用 `*-linux-amd64.deb`。

Windows: use `*-windows-x64-setup.exe`. macOS (Apple Silicon): use `*-macOS-arm64.dmg` or update in-app. Linux (Debian/Ubuntu): use `*-linux-amd64.deb`.
