新增法语界面支持，可在语言菜单选择 Français，即时切换并记住语言偏好。

Adds French interface support. Select Français in the language menu to switch instantly and retain your preference after restart.

## 法语支持 / French support

- 语言下拉菜单新增 Français，与中文和 English 并列；加宽语言选择框，完整显示法语名称。
- Adds Français alongside 中文 and English in the language menu, with a wider selector to display the name.
- 为现有 1219 条界面文本补齐法语翻译，涵盖工具栏、菜单、文件管理、编辑器、Git、SSH、传输、历史记录、设置及新手教程。
- Adds French translations for all 1,219 existing interface strings across toolbars, menus, file management, the editor, Git, SSH, transfers, history, settings, and the tutorial.
- 法语选择支持即时生效、保存和重启恢复，并可通过设置导入导出在设备之间迁移。
- French selection takes effect immediately, persists across restarts, and transfers between devices through settings export and import.

## 验证 / Validation

- 本机全量测试：1991 项通过、16 项跳过，另有 3777 项子测试通过；静态检查通过。
- Local full suite: 1,991 tests passed, 16 skipped, plus 3,777 passing subtests; static checks passed.

- 检查全部语言的翻译完整性及变量占位符一致性；Qt 界面回归覆盖下拉选项、即时切换、设置保存与新窗口恢复。
- Checks translation coverage and placeholder consistency for every supported language. Qt regressions cover the menu option, immediate switching, persistence, and restoration in a new window.
- 三平台构建和全量测试由发布流水线执行，macOS 安装包经过签名和 Apple 公证。
- The release pipeline builds and runs the full suite on all three platforms; macOS installers are signed and notarized by Apple.

## 下载 / Downloads

Windows：推荐 `*-windows-x64-setup.exe`；macOS（Apple Silicon）：推荐 `*-macOS-arm64.dmg`，也可通过应用内更新；Linux（Debian/Ubuntu）：使用 `*-linux-amd64.deb`。

Windows: use `*-windows-x64-setup.exe`. macOS (Apple Silicon): use `*-macOS-arm64.dmg` or update in-app. Linux (Debian/Ubuntu): use `*-linux-amd64.deb`.
