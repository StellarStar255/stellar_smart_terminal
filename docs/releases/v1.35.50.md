修复全局和本地快捷命令管理列表中长名称换行、最后一条难以选中的问题。

Fixes long names wrapping and the last item being hard to select in the global and local quick command managers.

- 长名称保持单行，超出部分显示省略号。悬停或选中条目后可查看完整名称。
- Long names stay on one line and end with an ellipsis when space runs out. Hover over or select an item to see its full name.
- 移除横向滚动条，加大行间距、纵向滚动条和默认窗口尺寸，滚动到底部即可完整看到并点击最后一条命令。
- Removes horizontal scrolling and enlarges the row spacing, vertical scrollbar, and default window. Scroll to the bottom to see and select the entire last row.
