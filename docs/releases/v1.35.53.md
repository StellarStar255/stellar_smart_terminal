端口转发现在可以为同一监听地址和端口保存多个不同的目标。添加规则后，可自行选择启动哪一条。启动遇到冲突时会提示，正在运行的规则会继续运行。

Port forwarding now lets you save several destinations for the same listen address and port. Choose which rule to start. If a port is already in use, the app reports the conflict and leaves the running rule in place.

右键选择「编辑转发规则…」即可修改监听端和目标。编辑会保留原有分组、勾选状态和自动启动设置。正在运行的规则需先停止再改。

Right-click a rule and choose “Edit Forwarding Rule…” to modify its listener or destination. Edits preserve group membership, the checkbox state, and the start-on-connect setting. Stop a running rule before changing its endpoints.
