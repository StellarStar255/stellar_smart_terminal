按 **⌘3**（Windows 和 Linux 上为 **Ctrl+3**）打开 Remote。面板已经打开时，再按即可在远程文件树与连接列表间切换，保留当前 SSH 会话、目录和选中的文件。

Press **Command+3** on macOS or **Ctrl+3** on Windows and Linux to open Remote. While the panel is open, press the same shortcut to switch between the remote file tree and host list. The SSH session, current directory, and selected file are preserved.

按 **⌘⌥3**（Windows 和 Linux 上为 **Ctrl+Alt+3**）显示或收起 Remote 面板。两项操作都可在「视图」菜单查看，也可以在「键盘快捷键」设置里自定义。

Press **Command+Option+3** on macOS or **Ctrl+Alt+3** on Windows and Linux to show or hide the Remote panel. Both actions appear in the View menu and can be customized in Keyboard Shortcuts.

## 下载 / Downloads

Windows uses `*-windows-x64-setup.exe`. On macOS (Apple Silicon), use `*-macOS-arm64.dmg` or update in the app. On Debian or Ubuntu, use `*-linux-amd64.deb`.
