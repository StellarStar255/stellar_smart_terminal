在任一窗口启停端口转发后，所有窗口的 Remote 主机列表都会立即更新。🔀 后的数字是该主机正在运行的规则数量，悬停可查看监听地址、端口和目标。更新会保留当前选中项，无需关闭转发对话框。

Starting or stopping a forward updates the Remote host list in every window immediately, even while the forwarding dialog is open. The 🔀 badge counts active rules, and hovering shows their listener and destination. The selected host stays selected.

Remote 面板的显示和收起改用 **⌘⇧3**（Windows 和 Linux 上为 **Ctrl+Shift+3**）。**⌘3** 仍用于打开 Remote 和在文件树、连接列表间切换。如果 macOS 的全屏截图仍使用 **⌘⇧3**，请先在系统键盘设置中为截图改键或停用该截图快捷键。

Use **Command+Shift+3** on macOS or **Ctrl+Shift+3** on Windows and Linux to show or hide Remote. **Command+3** still opens Remote and switches between files and hosts. If macOS uses **Command+Shift+3** for full-screen screenshots, reassign or disable the screenshot shortcut in System Settings first.
