在 macOS 上，从 Finder 复制一张或多张图片，再在 Stellar Smart Terminal 的 Codex 输入框按 **⌘V**。图片成为附件后，输入框会显示 `[Image #1]` 等标记，上方显示缩略图。调整窗口大小后缩略图会重新绘制，删除附件时会同步清除。

On macOS, copy one or more images in Finder and press **Command+V** in the Codex composer. Attached images appear as references such as `[Image #1]` with thumbnails above the input. Previews redraw after resizing and disappear when the attachment is removed.

终端状态栏现在会提示「已粘贴图片路径」。Codex 输入框中的图片标记表示附件已加入。

The terminal status bar now reports when an image path was pasted. The image reference in the Codex composer confirms the attachment.
