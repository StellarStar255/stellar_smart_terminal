## 快速命令

- 在命令面板中按名称或命令内容搜索全局和当前项目的预设。macOS 上按 **⌘K** 打开面板。
- 回车直接执行。按 **⌥↩／Alt+Enter** 或点击「填入终端」可以先修改再执行。多行预设可选择要填入的一行。
- 搜索结果下方显示当前标签和分屏。识别到前台 SSH 主机时也会显示主机名。点击「编辑预设」或按 **F2** 可直接打开选中的预设。
- 在预设管理中勾选置顶，常用命令就会出现在对应的菜单顶部。长列表按屏幕高度展开，「添加命令」和「管理预设」固定在底部。

## Quick Commands

- Search global and current project presets by name or command text. On macOS, open the command palette with **⌘K**.
- Press Enter to run the preset. Use **Option+Enter / Alt+Enter** or **Insert into Terminal** to edit a command before submitting it. For multiline presets, choose the line to insert.
- Search results show the target tab, pane, and any recognized foreground SSH host. Use **Edit Preset** or **F2** to open the selected preset directly.
- Pin frequently used presets from the preset manager. Long lists adapt to the screen height, with **Add Command** and **Manage Presets** fixed at the bottom.

## 下载 / Downloads

Windows 使用 `*-windows-x64-setup.exe`。macOS（Apple Silicon）使用 `*-macOS-arm64.dmg`。Linux（Debian/Ubuntu）使用 `*-linux-amd64.deb`。也可以在应用内检查更新。
