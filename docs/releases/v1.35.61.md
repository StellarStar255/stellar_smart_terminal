## Git 提交消息生成

- 暂存区有改动时，按暂存内容生成消息。生成期间如果 Git 改动发生变化、切换仓库或分支，或手动编辑了草稿，应用会保留当前草稿并丢弃旧结果。
- 正确处理 MiniMax-M3 的推理设置，以及空响应、输出截断、服务商错误和超时。错误提示保留状态码，并遮盖 API Key 和其他已识别的凭据。
- 未解决的合并冲突会提示先解决再生成。提交消息正文提到推理标签时，标签原样保留。
- 支持带查询参数的 API 网关地址，并在切换界面语言时保持生成进度提示。

## Git commit message generation

- Generate messages from staged changes when the index has changes. Keep the current draft if the Git changes, repository, branch, or draft changes while generation is running.
- Handle MiniMax-M3 reasoning settings, empty or truncated responses, provider errors, and timeouts. Error dialogs preserve status codes and redact recognized credentials.
- Unresolved merge conflicts prompt you to resolve them before generating a message. Literal reasoning tags in commit text are preserved.
- Keep API gateway query parameters intact and retain the progress label when switching languages.
