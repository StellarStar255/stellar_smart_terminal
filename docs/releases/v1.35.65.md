## 终端选区与链接

- 在 Codex 正文中按住鼠标并拖向上下边缘，可以跨页选择。反向拖动或正文延迟重绘时，选区会跟随已确认的正文位置，复制时排除固定状态栏。
- 复制按列排列的输出会保留缩进和列间空格。双击换行的中文文件名或带组合音标的单词，可以选中完整名称。
- 改进分数缩放下的链接定位。含中文路径的纯文本网址支持点击汉字的左右两半。
- 修复 Windows 不支持透传模式时的终端启动回退，以及 Linux 上 Python 3.10 批量压缩上传的问题。

- Linux 安装包会自动安装 Qt 打开 X11 窗口所需的运行库。

## Terminal selection and links

- Drag toward either edge of the Codex transcript to select across pages. Selection follows the transcript when you reverse direction or a redraw arrives late, and excludes the fixed status area.
- Copying column-aligned text preserves indentation and spacing. Double-clicking a wrapped Chinese filename or a word with combining accents selects the complete name.
- Link clicks follow the displayed cells at fractional scale factors. Both halves of a Chinese character in a plain-text URL point to the full address.
- Fixed terminal startup when Windows rejects ConPTY passthrough and compressed batch uploads on Linux with Python 3.10.

- The Debian package installs the libraries Qt needs to open an X11 window.

## 下载 / Downloads

macOS（Apple Silicon）使用 DMG，Windows x64 使用安装程序或便携 ZIP，Debian/Ubuntu 使用 DEB。也可以在应用内检查更新。
