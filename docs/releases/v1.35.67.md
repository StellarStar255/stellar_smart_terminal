## Window navigator activity

A blue-gray dot gently pulses beside a window while any of its terminals produces output. It fades from the list after about 1.5 seconds of silence. A steady green dot takes priority when something needs attention. If two panes request input, responding in one pane keeps the reminder for the other. Hidden or minimized navigators pause their animations, and status changes preserve your scroll position.

## Terminal and command palette fixes

- Improved selection highlighting after mouse release and delayed terminal redraws.
- Fixed stale quick commands when switching terminals and accidental execution while composing text with an input method.
- Improved paste handling and SSH host detection. The Help menu now lets you copy diagnostic information.

## 中文说明

窗口中任一终端有输出时，导航列表会显示灰蓝色呼吸点。输出停止约 1.5 秒后，呼吸点消失。需要查看或回应时，绿色常亮提醒优先显示。两个分屏同时等待输入时，回应其中一个会保留另一个的提醒。隐藏或最小化导航面板会暂停动画，状态变化也会保留列表滚动位置。

本版还改善了松开鼠标后遇到延迟重绘时的选区高亮、终端粘贴和 SSH 主机识别，修复了切换终端后快捷命令过时、输入法组词时误执行命令的问题。帮助菜单新增复制诊断信息的入口。

Apple 芯片 Mac 可下载已公证的 DMG 或 ZIP；Windows x64 可选安装程序或便携 ZIP；Debian 和 Ubuntu amd64 可下载 DEB。
