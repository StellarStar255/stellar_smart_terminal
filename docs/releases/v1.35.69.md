## Output indicators for background windows

The window you are viewing no longer shows a blue-gray pulse for its own output. Switch to another window and you can still see whether the previous one is producing output. The floating navigator follows the active terminal window. Each embedded navigator omits the pulse for its own window. Green attention indicators remain visible, including in the window you are using.

### Downloads

Choose the DMG or ZIP for Apple Silicon Macs, the installer or portable ZIP for Windows x64, or the DEB for Debian and Ubuntu amd64.

## 简体中文

当前窗口有输出时，导航列表不再显示它自己的灰蓝色呼吸点。切换到另一个窗口后，如果原窗口仍在输出，就能看到它的呼吸点。浮动导航跟随当前活动的终端窗口，内嵌导航隐藏自身窗口的呼吸点。需要查看或回应时，当前窗口仍会显示绿色提醒。

Apple 芯片 Mac 可下载 DMG 或 ZIP，Windows x64 可选安装程序或便携 ZIP，Debian 和 Ubuntu amd64 可下载 DEB。
