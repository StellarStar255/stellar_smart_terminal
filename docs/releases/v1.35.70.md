## Quick command search and terminal resource usage

Quick Commands and Local Quick Commands now open with search hidden. Choose **Show Command Search** at the bottom of either menu to start filtering immediately. Each window remembers the two choices separately when you restore your workspace.

Idle terminals redraw only the blinking cursor cell. Switching tabs releases the hidden terminal’s cached screen image, and ordinary ASCII logs use less scrollback memory. Your scrollback history remains available when you switch back.

### Downloads

Choose the DMG or ZIP for Apple Silicon Macs, the installer or portable ZIP for Windows x64, or the DEB for Debian and Ubuntu amd64.

## 简体中文

右键菜单中的「快速命令」和「本地快速命令」默认隐藏搜索框。勾选菜单底部的「显示命令搜索框」即可立即筛选。每个窗口分别记住两个菜单的选择，恢复工作区时一并恢复。

终端空闲时，光标闪烁只重绘一个字符格。切换标签页会释放隐藏终端的画面缓存，普通 ASCII 日志也更节省历史记录内存。切回标签后仍可查看原有历史。

Apple 芯片 Mac 可下载 DMG 或 ZIP，Windows x64 可选安装程序或便携 ZIP，Debian 和 Ubuntu amd64 可下载 DEB。
