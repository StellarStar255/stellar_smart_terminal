## Output dots for individual terminals and windows

For a terminal running a continuous monitor such as `watch -n 1 nvidia-smi`, right-click inside the terminal and clear **Show Output Dot for This Terminal**. Other terminals in that window can still light the gray output dot.

To mute a whole window, right-click its row in the Terminal Window List and clear **Show Output Dot for This Window**. Workspace restore remembers each window’s choice. Turning the window dot back on preserves individual terminal preferences. Both switches start enabled, and green attention indicators continue to work independently.

Right-click a tab title to change its output dots, or right-click a split handle to mute just that pane. In long quick-command menus, switching search on or off keeps Add Command, Manage Presets and the search toggle visible.

### Downloads

Choose the DMG or ZIP for Apple Silicon Macs, the installer or portable ZIP for Windows x64, or the DEB for Debian and Ubuntu amd64.

## 简体中文

运行 `watch -n 1 nvidia-smi` 等持续监控命令时，可以在终端内右键取消「显示此终端的输出灰点」。同一窗口里的其他终端仍可点亮灰点。

要关闭整个窗口的灰点，在终端窗口列表中右键对应窗口，取消「显示此窗口的输出灰点」。恢复工作区时会记住每个窗口的选择。重新启用窗口灰点后，各终端沿用自己的设置。两个开关默认开启，绿色提醒独立生效。

右键标签标题也可切换灰点。多分屏标签可以逐个选择，也可右键分屏把手，只关闭该分屏。长快速命令菜单在切换搜索框后，底部的添加命令、管理预设和搜索开关仍然可见。

Apple 芯片 Mac 可下载 DMG 或 ZIP，Windows x64 可选安装程序或便携 ZIP，Debian 和 Ubuntu amd64 可下载 DEB。
