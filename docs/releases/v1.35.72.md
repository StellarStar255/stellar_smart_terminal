## Quick command menu alignment and mouse selection

In long Quick Commands and Local Quick Commands menus, turning off search keeps **Add Command** visible and clickable. The command list and the footer now resize together. Footer labels align with command names, a darker background separates the actions from the list, and the search checkmark appears on the right.

Right-click a window in the Terminal Window List, a tab title, or a split to control its output dot. Each window remembers its choice when the workspace is restored.

### Downloads

Choose the DMG or ZIP for Apple Silicon Macs, the installer or portable ZIP for Windows x64, or the DEB for Debian and Ubuntu amd64.

## 简体中文

在较长的「快速命令」和「本地快速命令」菜单中，关闭搜索后仍可看到并点击「添加命令」。命令列表与底部操作区会同步调整高度。底部文字与上方命令名称左对齐，底色稍深，搜索开关的勾选标记移到了右侧。

在窗口列表、标签标题或分屏内右键，可分别切换相应的输出灰点。恢复工作区时，每个窗口会记住自己的选择。

Apple 芯片 Mac 可下载 DMG 或 ZIP，Windows x64 可选安装程序或便携 ZIP，Debian 和 Ubuntu amd64 可下载 DEB。
