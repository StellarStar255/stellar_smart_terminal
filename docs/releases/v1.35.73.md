## Terminal tabs and resource usage

Background tabs show a pulsing gray dot while a terminal produces output and a green dot for completion. Selecting a tab clears its badge. The selected tab stays unmarked even when its window loses focus. The terminal context menu also uses a smaller left margin.

Hidden terminals pause cursor blinking. Large recording updates retain only the recent output, and prompt detection reads the bottom 15 rows. The log panel bounds queued output while the window is inactive and preserves line breaks, indentation and Unicode characters across refreshes.

## 简体中文

后台标签有输出时显示灰色呼吸点，收到完成提醒时显示绿点，切到该标签即可清除。当前选中的标签保持无点，窗口失焦后也是如此。终端右键菜单的文字左侧留白已缩小。

隐藏终端会暂停光标闪烁；会话录制收到超大文本时只保留最近的输出；交互提示检测仅读取底部 15 行。日志面板限制后台积压，分批刷新时保留换行、缩进和完整的组合字符。
