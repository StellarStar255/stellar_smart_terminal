## Terminal activity indicators

Window and tab activity dots now follow changes to terminal text. Cursor updates, terminal queries, same-text repaints and changes to the model line beneath an idle Codex prompt no longer trigger the gray dot. New output and scrolling logs still trigger it.

## 简体中文

窗口列表和标签页的灰点现在依据终端文字变化显示。光标移动、终端查询、重复绘制相同文字，以及空闲 Codex 输入框下方的模型状态更新，都不会点亮灰点。新输出和滚动日志仍会提示。
