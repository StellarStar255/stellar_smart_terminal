## Terminal activity indicators

The idle animation around the Codex input prompt no longer lights the gray activity dot in the window navigator or tab bar. This includes Codex sessions started in the background and left unfocused.

## 简体中文

在后台启动 Codex 后，即使一直停留在其他窗口，空闲输入框周围的点阵动画也不会点亮窗口列表或标签页的灰点。新的终端输出仍会触发提示。
