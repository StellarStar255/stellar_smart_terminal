## Keep the window open after closing the last tab

Closing the last terminal tab leaves your project window open. On macOS, press Cmd+W again in the empty terminal area to close the window. To keep working, open a new terminal or click Start to run the selected preset. Workspace restore also remembers an empty terminal area.

Downloads are available for macOS (Apple Silicon), Windows (x64) and Linux (amd64).

## 简体中文

关闭最后一个终端标签后，项目窗口会保留。在 macOS 上，此时在空白终端区域再按一次 Cmd+W 才会关闭窗口。要继续工作，可以新建终端，或点「启动」运行当前预设。恢复工作区时也会保留零标签状态。

可下载 macOS（Apple 芯片）、Windows（x64）和 Linux（amd64）安装包。
