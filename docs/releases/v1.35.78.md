## Run quick commands from an empty terminal window

After closing the last tab, right-click the empty terminal area to open a new terminal, browse global or local quick commands, open the current folder, or copy its path. Choosing a command starts a shell in the current folder and runs the command. Browsing or dismissing the menu leaves the window empty.

## 简体中文

关闭最后一个标签页后，右键点击空白终端区，可以新建终端、浏览全局或本地快捷命令、打开当前目录，或复制目录路径。选中快捷命令时，应用会在当前目录新建 Shell 并执行命令。浏览或收起菜单时，窗口会保持空白。
