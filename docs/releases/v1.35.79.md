## Terminal startup, retries and window controls

- Type while a shell starts. Keystrokes, committed IME text and pasted text stay with the original terminal even if you switch tabs. On macOS and Linux you can switch tabs or cancel while the shell is starting.
- If startup fails, the terminal displays the error. Fix the cause and press Enter to retry in the original directory. Selected preset and quick commands run in order after a successful retry. Input typed during the failed attempt is cleared.
- Stopping a session in a split tab preserves its output and leaves the other panes running.
- An empty window now shows a button to start a terminal in the current directory. Window close prompts default to keeping the window open, and closing the last tab with a running process asks for confirmation.

## 简体中文

- Shell 启动期间即可输入。按键、输入法提交的文字和粘贴的文本都保留在原终端，切换标签也不会串到其他会话。macOS 和 Linux 上可以在启动期间切换标签或取消启动。
- 如果启动失败，终端会显示错误。修复原因后按回车，即可在原目录重试。成功后，所选预设和快捷命令按顺序执行；失败时手工输入的内容会被清除。
- 在多分屏标签里停止会话，会保留当前分屏的输出，其他分屏继续运行。
- 空窗口提供在当前目录新建终端的按钮。关窗确认默认保留窗口，关闭仍有运行进程的最后一个标签时也会提示确认。
