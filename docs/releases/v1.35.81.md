## Close the last terminal tab in one step

Closing the last terminal tab now stops its processes immediately and leaves the window open. Use the tab’s ×, the toolbar, the tab menu, or the close shortcut (⌘W on macOS). In a split tab, the shortcut closes the focused pane first.

From the empty window, start another terminal in the current directory, or press the close shortcut again to bring up the window close confirmation.

## 简体中文

关闭最后一个终端标签页时，里面的进程会直接停止，窗口保持打开。可以使用标签上的 ×、工具栏、标签右键菜单或关闭快捷键（macOS 为 ⌘W）。标签内有多个分屏时，快捷键会先关闭当前分屏。

在空窗口中，可以在当前目录新建终端，也可以再按一次关闭快捷键，调出关闭窗口的确认框。
