## Spring split panes and Quick Commands

- Terminal text adjusts to the final pane width as soon as the Spring animation ends. Repeated pane switches also release completed and interrupted animations.
- Enable **Confirm before running** for individual global or local presets. The confirmation shows the commands and defaults to Cancel. It applies to the context menu, command search and the Start button.
- Moving the pointer over a quick command highlights that command alone. Arrow keys continue from the highlighted row.
- The toolbar preset list shows a persistent scrollbar when more presets are available offscreen.

Download the macOS Apple silicon disk image or update ZIP, Windows x64 installer or portable ZIP, or Linux amd64 Debian package from this release.

## 简体中文

- Spring 分屏动画结束时，终端立即开始按最终宽度排版。连续切换分屏时，已完成或被中断的动画也会及时释放。
- 全局和本地预设均可单独勾选**执行前确认**。右键菜单、命令搜索和工具栏 Start 执行该预设时，会展示命令内容，默认选中取消。
- 快捷命令列表只高亮鼠标指向的命令，方向键可以从当前高亮行继续移动。
- 工具栏预设列表超出一屏时，滚动条持续可见。

本版提供 macOS Apple 芯片 DMG 和更新 ZIP、Windows x64 安装程序和便携 ZIP，以及 Linux amd64 的 DEB 包。
