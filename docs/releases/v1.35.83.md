## Maximize all terminal windows

- Choose **Maximize All Windows** below Refresh in the window navigator’s gear menu. Each terminal maximizes on its current display. Minimized terminals reopen, and fullscreen windows keep their state. The command works in both the embedded and floating navigator, even with a search filter active.
- Move a maximized terminal to another display and restore it there. During a group drag, maximized windows switch displays on release. A subsequent drag, resize or maximize takes precedence over a pending placement correction.
- Closing a navigator while its gear or window context menu is open now dismisses the menu safely.

Download the macOS Apple silicon DMG or update ZIP, Windows x64 installer or portable ZIP, or Linux amd64 Debian package from this release.

## 简体中文

- 在窗口导航器的齿轮菜单中，点击「刷新」下方的 **最大化所有窗口**，各个终端就会在各自屏幕上最大化。已最小化的终端会展开，全屏窗口保持原状。内嵌和浮动导航器均支持此命令，即使正在筛选列表也会作用于全部主窗口。
- 最大化的终端跨屏搬动后，可在目标屏幕还原。整组拖动时，最大化窗口在松手时切换屏幕。连续拖动、调整尺寸或最大化后，旧的位置校正会让位于最近一次操作。
- 齿轮菜单或窗口右键菜单打开时，关闭导航器也能安全收起菜单。

本版提供 macOS Apple 芯片 DMG 和更新 ZIP、Windows x64 安装程序和便携 ZIP，以及 Linux amd64 的 DEB 包。
