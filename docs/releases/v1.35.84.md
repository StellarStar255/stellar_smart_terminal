## Zoom the editor and terminal together

- Press **Cmd+=** or **Cmd+-** on macOS (**Ctrl+=** or **Ctrl+-** on Windows and Linux) with either pane focused. The editor and all terminal panes in that window now stay at the same text size, including when you choose a custom GUI font size. The file tree also follows content zoom when you first open it.
- At 8 or 32 pt, a single press in the opposite direction changes the size immediately, even after repeated presses at the limit.
- Move a terminal tab to another window and every split pane adopts the destination window’s text size while the shell session continues.

Downloads include the macOS Apple silicon DMG and update ZIP, the Windows x64 installer and portable ZIP, and the Linux amd64 Debian package.

## 简体中文

- 在编辑器或终端中按 **⌘=** 放大、**⌘-** 缩小（Windows 和 Linux 使用 **Ctrl+=** 和 **Ctrl+-**）。同一窗口里的编辑器和所有终端分屏会保持相同字号，手动设置 GUI 字号后也能同步。首次打开文件树时，它也会跟随当前的内容缩放级别。
- 达到 8 或 32 pt 后，即使继续按了多次，反向按一次也能立即调整字号。
- 将终端标签移到另一个窗口时，所有分屏会采用目标窗口的字号，正在运行的 shell 会话会继续运行。

本版提供 macOS Apple 芯片 DMG 和更新 ZIP、Windows x64 安装程序和便携 ZIP，以及 Linux amd64 的 DEB 包。
