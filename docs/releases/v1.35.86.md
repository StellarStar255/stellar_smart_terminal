## Window navigation and SSH reconnects

- Right-click a window in the navigator and choose **Set Folder Alias…**. The navigator remembers the name for that folder the next time you open it. Folders with the same name at different paths can have different aliases. Clear the field to restore the default name.
- Each window’s output dot pulses at its own pace. The embedded and floating navigators show the same rhythm for the same window, even after you filter or reorder the list.
- Double-click a remote host to return to its files. Repeated clicks during login share one connection attempt. After a temporary SFTP disconnect, the browser can reuse a verified password and reopen the previous folder while your SSH terminal keeps running. If the folder has been removed, the browser opens the remote home folder.
- Passwords are scoped to the connection and kept in memory. If the server rejects a remembered password, you can enter a replacement on the same live SSH connection. Cancelling a password prompt and immediately retrying works even on systems with a coarse clock. Disconnecting clears the panel’s remembered passwords. One-time codes are requested again when needed.

Downloads include the macOS Apple silicon DMG and update ZIP, Windows x64 installer and portable ZIP, and Linux amd64 Debian package.

## 简体中文

- 在导航列表中右键点击窗口，选择 **设置文件夹别名…**。下次打开这个文件夹时，列表会显示你起的名字。不同路径下的同名文件夹可以分别命名，清空别名即可恢复默认名称。
- 每个窗口的输出圆点都有自己的呼吸节律。同一窗口在侧栏和浮动导航器里的节律一致，筛选或拖动排序后依然连贯。
- 双击远程主机即可返回文件列表，登录期间连续双击只发起一次连接。SFTP 临时断开后，文件面板可复用已验证的密码回到原目录，已有 SSH 终端继续运行。原目录已删除时，会回到远程主目录。
- 密码按连接信息区分，只保存在内存中。旧密码被服务器拒绝后，可在同一条有效的 SSH 连接上输入新密码；取消密码框后可以立即双击重试。主动断开会清除面板记住的密码。服务器要求一次性验证码时会重新询问。

本版提供 macOS Apple 芯片 DMG 和更新 ZIP、Windows x64 安装程序和便携 ZIP，以及 Linux amd64 的 DEB 包。
