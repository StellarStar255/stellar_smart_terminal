## SSH passwords and file list text size

- In the macOS Remote panel, select **Save to macOS Keychain** when entering an SSH login password. After a successful login, the app can use it again across restarts. When the server password changes, select **Update password in macOS Keychain**. To remove it, right-click the host and choose **Forget Login Password in Keychain**. One-time codes are requested separately.
- Renaming a host in the app moves its Keychain entry when the server, account, port and jump host still match. A delayed login respects a newer password or a request to forget it from another window.
- Password-only servers can prompt for a password through an SSH jump host even when the client has no local keys.
- **GUI Font** controls file names in the local and remote file lists. Zooming the terminal and editor together leaves the file lists at the selected interface size.

## 简体中文

- 在 macOS 的 Remote 面板输入 SSH 登录密码时，可勾选「保存到 macOS 钥匙串」。成功登录后，重新启动应用也能复用密码。改密时可勾选「更新 macOS 钥匙串中的密码」，右键主机可选择「从钥匙串忘记登录密码」。一次性验证码仍单独询问。
- 在应用内给主机改名时，如果服务器、账户、端口和跳板都相同，已保存的密码会随之迁移。另一窗口已更新或删除密码时，较早的登录即使稍后完成，也不会写回旧密码。
- 通过 SSH 跳板连接仅支持密码认证的目标机时，即使本机没有可用私钥，也能正常输入密码登录。
- 本地和远程文件列表的字号由 **GUI Font** 控制。同步缩放终端和编辑器时，文件名保持所选界面字号。
